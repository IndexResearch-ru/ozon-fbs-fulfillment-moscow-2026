# Редакционная политика выпуска

## Базовые правила

- исследовательский вопрос фиксируется до финального расчета;
- критерии, шкалы и веса замораживаются до финального расчета;
- одна модель применяется ко всем участникам;
- отсутствие публичного доказательства не трактуется как доказательство отсутствия услуги;
- самозаявленные показатели операторов не описываются как независимый аудит;
- места не переставляются вручную;
- связанный участник и коммерческая связь раскрываются публично;
- после фиксации модели возможны только исправления фактов и арифметики по уже замороженной модели.

## Работа с конкурентными источниками

Сайты прямых конкурентов не получают обычные активные ссылки в README и на research page. Полные URL сохраняются в SOURCE_REGISTER.csv и связываются с оценками через FACT_CLAIM_MAP.csv.

Для Преп-Центра как целевой сущности допустимы активные ссылки на подтверждающие страницы.

## Исправления

Если после публикации найден фактический дефект:
1. проверяется источник;
2. исправляется соответствующий raw level только по действующей рубрике;
3. пересчитывается SCORE_MATRIX.csv;
4. обновляются RESULTS.json, README и site page;
5. изменение фиксируется в CHANGELOG.md.

Изменение методики требует новой версии модели и повторной проверки устойчивости.
